# pomotivity

This is a productivity app for note taking, task tracking, and time management.


## Running this project

This is a react + vite program which will require node. To install node visit the official [Node.js](https://nodejs.org/en) website.

1. After cloning the repository and navigating into the directory run the following command to install the dependencies for this project.
```
npm install
```
2. Then to start the dev server run the following command and click the link to visit.
```
npm run dev
```
Currently it runs on local host with the specified port number. Should look similar to the following.
```
  VITE v8.0.10  ready in 936 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```
